# VisionAssist 2.0 👁️

VisionAssist 2.0 is a voice-first accessibility web application designed to help visually impaired users read, understand, and interact with digital and physical information.

## 🚀 Features

- 🎙️ Talk to Website — Voice-based interaction
- 🌐 Indian Language Support — Hindi, Punjabi, English and more
- 📷 Vision Assist — Camera-based scene understanding
- 📄 Document Reader — Read and understand documents
- 📚 Study Mode — Helps students understand study material
- 📝 Smart Forms — Voice assistance for form fields
- 🛍️ Product Reader — Reads visible product information
- 🔒 Privacy Mode — User-controlled information sharing
- 🤝 Trusted Helper — Human fallback assistance

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS
- Node.js
- Express.js
- Gemini API
- Web Speech API
- Camera / MediaDevices API
